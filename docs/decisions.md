# Действующие решения

## Объём — согласован 2026-11-02

Пользователь поручил первые три шага: проверить штатный OAuth на фиктивных credentials, переделать авторизацию шлюза и ввести строгую проверку формата. Эти шаги выполнены последовательно. Развёртывание VPS, клиентский launcher и сетевые правила Mac в объём не входят. Рабочая архитектура: нативный клиент на Mac, шлюз на VPS, браузерные чаты напрямую.

Модули: proxy — транспорт и авторизация шлюза; privacy — распаковка и проверка формы; audit — изолированная проверка настоящего клиента. Стек Bun 1.3+, TypeScript strict, h11 1.0.21, desy 0.0.29. Использование desy для валидации отдельно поручено пользователем 2026-11-02.

## Proxy

- Вход: отдельный `x-gateway-token` и клиентский `Authorization: Bearer`. `x-api-key`, отсутствие/неверные/неоднозначные credentials отклоняются. Сравнение gateway token по SHA-256 через timingSafeEqual. Client access token проверяется на формат, но не на действительность: это делает upstream.
- Серверного OAuth access token в конфигурации нет. Upstream получает токен текущего запроса без подмены и кэширования; `x-gateway-token` не пересылается. Запись токенов в файлы, логи или чтение Keychain не выполняются. Gateway token должен отличаться от access token.
- Origin исполняемого сервера фиксирован: https://api.anthropic.com. Программный startProxy допускает другой origin для тестов; HTTP допустим только на loopback. Входящий Host/абсолютный request-target не меняет upstream. Redirect запрещён.
- Только POST /v1/messages и /v1/messages/count_tokens с необязательным одиночным beta=true. API version только 2023-06-01, при отсутствии заголовка ставится она. OAuth endpoints и телеметрия не поддерживаются.
- Заголовки upstream: content-type, accept, accept-encoding, anthropic-version, anthropic-beta, authorization. Неизвестные заголовки и cookies не пересылаются. В ответе разрешены content-type, request-id, retry-after, anthropic-ratelimit-*.
- Bind по умолчанию 127.0.0.1:8443. Внешний listener требует TLS cert/key. Отключение TLS verification запрещает запуск.
- Лимит тела 16 MiB, deadline 10 минут вместе с SSE, idleTimeout 60 секунд. Отключение клиента отменяет upstream. После начала SSE ошибка прерывает поток.
- Сохраняется прямое чтение Request: h11 createSizeLimitModule теряет AbortSignal. Поток ответа использует явный cancel для Bun.
- Логи содержат только route/status/durationMs до начала ответа. Ошибки не включают тело, URL или секреты.

## Privacy и схемы

- `sanitizeBody({ body, route, encoding, maxBodyBytes })` возвращает Buffer либо фиксированную ошибку 400/413/415. Route — messages или count_tokens. Схемы вынесены в src/privacy/schema.ts внутри того же модуля.
- Identity/gzip/deflate(zlib)/br; составные и неизвестные кодировки отклоняются. Распакованный размер ограничивается внутри декомпрессора. Проверяются UTF-8 и JSON через штатный JSON.parse.
- Схемы реализованы на desy 0.0.29 (версия закреплена). Объекты закрыты по умолчанию; адаптер createObject исключает массивы и создаёт shape без прототипа. Optionality добавляется через отдельную обёртку, чтобы не мутировать общие схемы; пустые строки разрешены без допуска null/undefined. По согласованию с пользователем самописный checkJsonStructure удалён. Дубликаты обрабатываются по правилам JSON.parse (последнее значение), отдельного ограничения глубины нет.
- Закрытые схемы протокольных объектов: обязательные поля, типы, перечисления, диапазоны известных числовых параметров. У count_tokens отдельный набор полей. Новые поля/типы не пересылаются до расширения схемы и тестов.
- Поддерживается ограниченное подмножество: text/image/thinking/redacted_thinking/tool_use/tool_result, custom tools, thinking, output_config и clear_thinking_20251015. Полный список в README и schema.ts. Document, server tools и неизвестные beta-блоки пока отклоняются.
- Tool input, JSON Schema инструментов/вывода и текст — пользовательские данные с произвольными ключами. metadata разрешает только user_id как непрозрачную строку. Проверка формата не является фильтром содержимого или анонимизацией.
- Metadata и идентификаторы сохраняются, подмены нет. Прежнее удаление metadata отменено при переходе к клиентскому OAuth. Принятые декодированные байты возвращаются без сериализации: подписи, форматирование и точные числовые литералы не меняются.
- При ошибке никакого upstream-вызова и возврата к непроверенному исходному телу нет.

## Audit

- macOS sandbox-exec, отдельные временные config/tmp/cwd, искусственный fixture. Не наследует credentials, не подменяет HOME. Реальные пользовательские каталоги, Keychain и известные Keychain Mach-сервисы запрещены; разрешён один mock localhost-порт.
- Preflight проверяет разрешённый/запрещённый локальные порты и запрет чтения синтетического внешнего файла. При неудаче Claude не запускается.
- Восемь сценариев: OAuth из временного файла, OAuth из env, API-key сообщение/Read/resume, safe-mode, Read/resume через proxy. OAuth использует safe-mode: bare OAuth-сценарий не подтвердился. Settings/MCP пустые, телеметрия отключена, инструмент только Read для fixture.
- В proxy-сценариях проверены точное совпадение upstream Bearer с фиктивным access token, сохранение metadata и отсутствие ключа шлюза на upstream. Проверяются SSE, tool_result и сохранение контекста resume.
- В отчёте только структура/длины и булевы результаты сравнения, не credentials/идентификаторы/диалоги. Временные credentials-файлы удаляются после сценария; вся папка удаляется в finally.
- 2026-11-02: восемь сценариев 2.1.281 прошли; docs/oauth-audit.json и docs/oauth-audit.md. После упрощения проверки JSON прошли 31 автоматический тест, check и build. Стенд с настоящим клиентом после этой замены повторно не запускался.

## Npm-пакет — согласован 2026-11-02

- Подготовка npm-дистрибутива aigan@0.1.0: исполняемая команда aigan, справка и версия, запуск без аргументов. Требуется Bun >=1.3.0; Node.js runtime не поддерживается.
- В bin указан dist/main.js с shebang /usr/bin/env bun. files разрешает только dist/main.js; npm добавляет package.json/README/license. Пакет — CLI, публичный программный API и декларации внутренних модулей не публикуются.
- Зависимости h11/desy остаются external, устанавливаются пакетным менеджером. prepack выполняет check/test/build, версия CLI берётся из package.json при сборке.
- Имя сейчас не занято по registry; публикация ещё не выполнялась. Авторизация npm требует восстановления (whoami вернул 401).
- Пользователь выбрал MIT; package.json и LICENSE содержат соответствующую лицензию.

## Остаётся нерешённым

- Штатный OAuth refresh и обмен кода авторизации используют отдельный TOKEN_URL. ANTHROPIC_BASE_URL не перенаправляет их. Произвольный CLAUDE_CODE_CUSTOM_OAUTH_URL запрещён встроенным списком клиента. Требуется отдельно выбрать и проверить сетевой путь авторизации до полного запрета прямого выхода.
- Настоящий Keychain, реальный аккаунт, refresh, все beta-функции и производственный TLS не проверялись. Mock не доказывает принятие запросов Anthropic или соответствие условиям сервиса.
- VPS, macOS firewall, клиентский launcher и возможные дополнительные сетевые маршруты ещё не реализованы.
